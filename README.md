# かいごしごと リニューアル案

介護施設で働く人向けの求人サイトを新規に立ち上げるための実装案。3方向のデザインパターンをそれぞれ完全な静的ページとして実装しています。

`eiyoushi-redesign`（栄養士向けサイトのリニューアル案）と同じ会社・同じ媒体型モデルの新規サイトという位置づけです。**`kaigo.shigotolink.com` のような既存サブドメインは存在しません**（確認済み）。ドメインも未取得のため、仮ブランド名「kaigo.」で実装しています。

## 見方

```
pattern-a/index.html   … 信頼の実務型（トップページ）
pattern-a/list.html    … 求人一覧（検索フィルター付き）
pattern-a/job.html, job-2.html〜job-8.html       … 求人詳細（掲載8求人ぶん、すべて別ページ）
pattern-a/apply.html, apply-2.html〜apply-8.html … 応募する（求人ごとの5ステップ応募フォーム）
pattern-a/faq.html     … よくある質問
pattern-a/about.html   … サイトについて
pattern-a/terms.html   … 利用規約（サンプル、要法務確認）
pattern-a/privacy.html … プライバシーポリシー（サンプル、要法務確認）
pattern-a/contact-company.html … 掲載のお問い合わせ（企業向け）
pattern-a/column.html  … お仕事コラム一覧
pattern-a/column-shikaku.html      … コラム：資格の取り方
pattern-a/column-mikeiken.html     … コラム：未経験からの転職
pattern-a/column-yakin.html        … コラム：夜勤あり/なしの働き方
pattern-b/ , pattern-c/ … 同じ27ページ構成をB・Cのデザインで実装
assets/img/             … 3パターン共通で使う写真（未生成、下記「写真について」参照）
_data.py, _patterns.py, _gen_css.py, _gen_html.py … 全ページを生成するPythonスクリプト
```

各パターンとも、トップページ→求人一覧→求人詳細→応募フォーム、まで実際にリンクをたどって遷移できます。掲載中の8求人はそれぞれ独立した`job-N.html`/`apply-N.html`を持っており、どの求人カードをクリックしても対応する求人・応募ページに遷移します（`eiyoushi-redesign`で発生した「全カードが同じ詳細ページに飛ぶ」問題を、最初から回避する設計にしています）。

ローカルで確認する場合は、このフォルダ直下で以下を実行してください。

```bash
python -m http.server 8080
```

その後 `http://localhost:8080/pattern-a/` のようにアクセスすると各パターンを確認できます。

内容（求人データ・カテゴリ・FAQ・コラム本文など）を変更する場合は、`_data.py` を編集してから `python _gen_html.py` を再実行してください。色・フォントなどデザイントークンを変更する場合は `_patterns.py` を編集して `python _gen_css.py` を再実行してください（3パターンぶん一括で再生成されます）。

## 前提：媒体型（求人メディア）であって、エージェント型ではない

`eiyoushi-redesign`での学びを踏まえ、最初から媒体型（会員登録不要・直接応募）で設計しています。介護業界で名前が挙がる大手（きらケア・レバウェル介護・マイナビ介護職・介護ワーカーなど）はいずれも厚生労働大臣認可の職業紹介事業＝エージェント型でしたが、これらはデザインの参考にはしても、会員登録・スカウト・アドバイザー面談といった導線は取り込んでいません。構造面は[ウェルミージョブ（旧カイゴジョブ）](https://kaigojob.com/)を実際に操作して参考にしました（切り口別の求人レール、職種×エリアのクロスマトリクス、「利用者の声」セクションなど）。

## 3パターンの方向性

| パターン | コンセプト | 基調色 | 口コミ | ヒーロー |
|---|---|---|---|---|
| A: 信頼の実務型 | 大きな写真1枚と余白で見せるミニマル構成 | ディープネイビー `#1E4E7A` | なし | フルブリード写真 |
| B: あたたかい安心型 | 丸ゴシック・チェックリストで柔らかい印象 | セージグリーン `#7A9D54` + テラコッタ `#C1592E` | あり | 2カラム（チェックリスト＋写真） |
| C: 現場のリアル型 | 明朝の見出しで実務感を出しつつ、現場のリアルな条件を見せる | ネイビー `#2B3A55` + マスタード `#D9A441` | あり | フルブリード写真 |

「利用者の声（口コミ）」セクションは3パターンのうちB・Cにのみ設置しています（Aは条件面のデータで信頼を出す方向、B・Cは実際に転職した人の声で安心感を出す方向、という役割分担）。

## 対象職種・施設種別について

「介護施設で働く人全般」を対象にしているため、職種は介護職員・ヘルパーだけでなく、生活相談員・ケアマネージャー（介護支援専門員）・サービス提供責任者・施設長候補・看護師（施設内）まで幅広く扱っています。施設種別は特別養護老人ホーム・介護老人保健施設・有料老人ホーム・サービス付き高齢者向け住宅・デイサービス・訪問介護の6種類です。掲載中の8求人は、この職種・施設種別が重複しないように組み合わせています。

## 求人一覧・求人詳細・応募導線について

`eiyoushi-redesign`の最終形（求人ごとに個別の詳細・応募ページを持つ設計）をそのまま踏襲しています。

- **求人一覧**（`list.html`）: キーワード・エリア・雇用形態に加えて、職種／施設種別／こだわり条件をチェックボックスのピルで絞り込める形にしています。
- **求人詳細**（`job.html`ほか）: 施設名・給与・ハイライト・「この求人のポイント」・仕事内容／募集要項のスペック表・似ている求人、という構成です。
- **応募フォーム**（`apply.html`ほか）: 会員登録なしの5ステップウィザードです。ステップ1〜2は施設種別・資格のタイル選択、ステップ3は転職時期＋都道府県、ステップ4は氏名・生まれ年、ステップ5は連絡先です。
- **会員登録・ログインは存在しません**。ヘッダーにはナビゲーションのみで、CTAボタンも設置していません。

## 実装時の注意点

- すべて素のHTML/CSSで、フレームワーク非依存です。
- 検索フォーム・各種CTAは見た目のみで、実際の検索・送信処理は未実装です。
- 掲載している求人8件・統計数値（掲載求人数など）はすべて仮のサンプルです。実データに差し替えてください。
- 「利用者の声」（パターンB・C）は実在しないサンプルです。ページ内にもその旨を明記しています。
- モバイル幅（720px以下）ではハンバーガーメニューと画面下部固定のCTAバーに切り替わります。ナビゲーションが5項目あるため、ハンバーガーへの切り替えは1040px以下から行っています（`eiyoushi-redesign`で発生した「721〜1040px幅でナビが折り返す」不具合を、最初から踏まえた設計です）。
