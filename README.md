# かいごしごと リニューアル案

介護施設で働く人向けの求人サイトを新規に立ち上げるための実装案です。`eiyoushi-redesign`（栄養士向けサイトのリニューアル案）と同じ会社・同じ媒体型モデルの新規サイトという位置づけですが、**データ構造・コンポーネントは共有していません**。介護の求人媒体（ジョブメドレー／ウェルミージョブ／コメディカルドットコム／e介護転職）を実測調査したうえで、介護特有の軸（夜勤の有無、職種×施設種別、掲載情報の充実度）を中心に3パターンとも作り直しています。

`kaigo.shigotolink.com` のような既存サブドメインは存在しません（確認済み）。ドメインも未取得のため、仮ブランド名「kaigo.」で実装しています。

## 3パターンの方向性

3パターンは色・書体だけでなく、トップページの構成・求人カードの作り・求人詳細ページの並び順そのものが異なります。

| パターン | コンセプト | ヒーロー | 求人カード | 書体 | 利用者の声 |
|---|---|---|---|---|---|
| A: 夜勤で選ぶ | 職種6色コーディング・職種×施設種別マトリクス・高密度 | 夜勤3分岐セレクタ | 横長・高密度 | BIZ UDPGothic | なし |
| B: 1日が見える | 出退勤タイムラインを軸にした読み物型 | 1日のタイムライン | 縦型・大きな写真 | Klee One + Noto Sans JP | あり |
| C: 条件で絞る | 検索フォーム主導・給与相場などのデータ比較 | 検索フォーム | テーブル行型 | IBM Plex Sans JP | あり |

```
pattern-a/apply.html, apply-2.html〜apply-8.html … 応募する（求人ごとの5ステップ応募フォーム）
pattern-a/faq.html     … よくある質問
pattern-a/about.html   … サイトについて
pattern-a/terms.html   … 利用規約（サンプル、要法務確認）
pattern-a/privacy.html … プライバシーポリシー（サンプル、要法務確認）
pattern-a/contact-company.html … 掲載のお問い合わせ（企業向け）
pattern-a/column.html  … お仕事コラム一覧
pattern-a/column-kyujinhyo.html … コラム：求人票のどこを見ればギャップが減るか
pattern-a/column-yakin.html    … コラム：夜勤あり/なし/専従の違い
pattern-a/column-shikaku.html  … コラム：資格と給与の関係
pattern-a/column-mikeiken.html … コラム：無資格・未経験からの転職

_gen_css.py  … style.cssを生成
_gen_html.py … 全HTMLページを生成
```

各パターンとも、トップページ→求人一覧→求人詳細→応募フォーム、まで実際にリンクをたどって遷移できます。掲載中の8求人はそれぞれ独立した`job-N.html`/`apply-N.html`を持っています。

ローカルで確認する場合は、このフォルダ直下で以下を実行してください。

```bash
python -m http.server 8080
```

その後 `http://localhost:8080/pattern-a/` のようにアクセスすると各パターンを確認できます。

内容（求人データ・職種・施設種別・FAQ・コラム本文など）を変更する場合は `_data.py` を編集してから `python _gen_html.py` を再実行してください。色・書体・構成（どのセクションを出すか）を変更する場合は `_patterns.py` を編集して `python _gen_css.py` と `python _gen_html.py` を再実行してください（3パターンぶん一括で再生成されます）。

## 前提：媒体型（求人メディア）であって、エージェント型ではない

`eiyoushi-redesign`での学びを踏まえ、会員登録不要・直接応募の媒体型で設計しています。介護業界で名前が挙がる大手（きらケア・レバウェル介護・マイナビ介護職・介護ワーカーなど）はいずれも職業紹介事業＝エージェント型ですが、これらの導線（会員登録・スカウト・アドバイザー面談）は取り込んでいません。参考にしたのは媒体型のジョブメドレー・ウェルミージョブ（旧カイゴジョブ）・コメディカルドットコム・e介護転職で、いずれも実際に操作したうえで、条件別の求人レール・職種×エリアのクロスマトリクス・「1日の流れ」「働く人の声」などの掲載情報を軸にした構造を取り入れています。

## データ構造について

介護は「職種」と「施設種別」の2軸で求人が決まる点が栄養士（1軸）と異なるため、`_data.py` に次の構造を持たせています。

- `SHOKUSHU` / `SHISETSU`：職種6種（介護職員・生活相談員・ケアマネージャー・サービス提供責任者・施設長・施設内看護師）と施設種別7種（特養・老健・有料・グループホーム・サ高住・デイ・訪問介護）
- `MATRIX`：職種×施設種別の件数クロス表（サビ責×特養のように制度上ありえない組み合わせは0件）
- `YAKIN_AXIS`：夜勤なし／夜勤あり／夜勤専従の3分類（介護の求人選びで最初に決まる軸）
- `RAILS`：カテゴリではなく「求人が満たす条件」「掲載情報の有無」で求人を束ねる切り口（例：「1日の流れが載っている求人」「働く人の声が読める求人」）
- 各求人には `has_timeline` / `has_voice` / `photo_count` / `pay_rows`（給与内訳）/ `office`（職員構成）/ `selection`（選考プロセス）を持たせ、求人ごとに掲載情報の充実度が異なる状態を再現しています

## 対象職種・施設種別について

「介護施設で働く人全般」を対象にしているため、介護職員・ヘルパーだけでなく、生活相談員・ケアマネージャー（介護支援専門員）・サービス提供責任者・施設長候補・看護師（施設内）まで幅広く扱っています。施設種別は特養・老健・有料老人ホーム・グループホーム・サービス付き高齢者向け住宅・デイサービス・訪問介護の7種類です。

掲載中の8求人は6職種すべてを網羅していますが、介護職員が3件と多くなっています。これは掲載求人全体でも介護職員が約49%（3,186件／6,524件）を占めるためで、意図的に実勢へ寄せています。

## 求人一覧・求人詳細・応募導線について

- **求人一覧**（`list.html`）: キーワード・夜勤・職種・施設種別・雇用形態・エリア・こだわり条件（25種）で絞り込める形にしています。
- **求人詳細**（`job.html`ほか）: パターンごとに並び順が異なります（Aは仕事内容→給与→要項→1日の流れ、Bは写真ギャラリー→1日の流れ→働く人の声→仕事内容、Cは募集要項→給与→仕事内容→1日の流れ、の順）。共通して、給与の内訳・募集要項・事業所の職員構成・選考プロセス・似ている求人を掲載しています。
- **応募フォーム**（`apply.html`ほか）: 会員登録なしの5ステップウィザードです。ステップ1〜2は施設種別・保有資格のタイル選択、ステップ3は転職時期＋都道府県、ステップ4は氏名・生まれ年、ステップ5は連絡先です。
- **会員登録・ログインは存在しません**。ヘッダーにはナビゲーションのみで、CTAボタンも設置していません。

## 実装時の注意点

- すべて素のHTML/CSSで、フレームワーク非依存です。
- 検索フォーム・各種CTAは見た目のみで、実際の検索・送信処理は未実装です。
- 掲載している求人8件・統計数値（掲載求人数など）はすべて仮のサンプルです。実データに差し替えてください。
- 「働く人の声」（パターンB・C）は実在しないサンプルです。ページ内にもその旨を明記しています。
- 夜勤には負のイメージがつきやすいため、夜勤まわりの表現には次の原則を置いています。①3択は「我慢の度合い」ではなく「何が手に入るか」で並べる、②「夜勤あり」を警告色（赤・オレンジ）で塗らない。求人カードと求人詳細の夜勤チップは、昼＝淡い緑・夜＝藍という優劣のない対比にしています、③ヒーロー写真は夜勤を暗く見せず、夜勤明けの申し送りなど「一人ではない」場面を使う。
- トップページのコピーは、H1を16字以内・ヒーローの説明文とセクションのリード文を各50字以内に抑える方針で書いています。求人ボックス等からの流入で「まずどんなサイトか見る」段階の読み手を想定しているためで、それ以上の説明が必要な内容は `column-kyujinhyo.html`（求人票の見方）などのコラムに逃がしています。コピーを増やす場合はこの上限を意識してください。
- モバイル幅（720px以下）ではハンバーガーメニューと画面下部固定のCTAバーに切り替わります。ナビゲーションが5項目あるため、ハンバーガーへの切り替えは1040px以下から行っています。
